# Building Your First Website

A two-session workshop for grades 7–11 by Xavier Wang.

- **Session 1 · Website Foundations:** plan your audience, purpose, and content; build with HTML; style with a separate CSS stylesheet; meet JavaScript; make it usable on every screen.
- **Session 2 · Build with AI:** use AI tools for design, coding, and debugging; write useful prompts; improve the design; add an interaction; iterate, test, and showcase.

**Open the workshop in your browser:**
https://xavierwang2009.github.io/DigitalFuture-Learning-/01-building%20your%20first%20website/

No account needed. Your work is saved in your own browser, and nothing is sent to an AI service.
