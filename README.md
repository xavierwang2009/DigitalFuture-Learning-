## Code Playground

Test and preview the website you build: paste or load your HTML, CSS, and JavaScript, see it at phone, tablet, and desktop sizes, and read console messages and errors.

**[Open the code playground](https://xavierwang2009.github.io/DigitalFuture-Learning-/playground/)** · files in [`playground/`](playground/)

In the playground, press **Use my workshop code** to bring in what you wrote in the lessons (same browser), or **Load my files** to open the `my-website.html`, `style.css`, and `script.js` you downloaded.

## Working offline

Download this repository (Code → Download ZIP), unzip it, and open `01-building your first website/index.html` or `playground/index.html` in a browser. Keep the folders together, because the playground uses the lecture's stylesheet and fonts.
